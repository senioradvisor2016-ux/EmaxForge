# SD-KORT BOOT PROBLEM ANALYS

**Datum:** 2026-03-06  
**Problem:** EMAX II bootar inte från SD-kortet

---

## 🔍 KRITISKA PROBLEM I "FUNKAR EJ/HD0.hda"

### 1. **BOOT SIGNATURE FEL** ❌ KRITISKT
- **FUNKAR EJ:** `0x00 0x00`
- **FUNKAR:** `0x78 0x82` ✅
- **Problem:** EMAX II kräver boot signature för att känna igen bootbar disk!
- **Impact:** EMAX II kommer inte ens försöka boota från disken

### 2. **BANK COUNT FEL** ❌ KRITISKT
- **FUNKAR EJ:** `0` (header field 0x14)
- **FUNKAR:** `90` ✅
- **Problem:** Bank count är diskstorleks-identifierare, inte antal banks!
- **Impact:** EMAX II kan inte identifiera diskstorleken korrekt

### 3. **CLUSTER AREA START FEL** ❌ KRITISKT
- **FUNKAR EJ:** `sector 0` (0x00000000)
- **FUNKAR:** `sector 98` (0x00000062) ✅
- **Problem:** Cluster area start är 0, vilket betyder att diskstrukturen är helt fel!
- **Impact:** EMAX II kan inte hitta cluster area och kan inte läsa OS eller banks

### 4. **FAT ENTRY 0 FEL** ❌ KRITISKT
- **FUNKAR EJ:** `0x0080` (fel byte order!)
- **FUNKAR:** `0x8000` ✅
- **Problem:** Byte order är fel - borde vara little-endian 0x8000
- **Impact:** FAT-tabellen är korrupt

### 5. **FAT ENTRY 1 FEL** ❌ KRITISKT
- **FUNKAR EJ:** `0x0002` (pekar till cluster 2)
- **FUNKAR:** `0x7FFF` (END marker) ✅
- **Problem:** OS är markerad som multi-cluster kedja istället för END
- **Impact:** EMAX II kan inte hitta OS-slutet

### 6. **OS DATA FEL** ❌ KRITISKT
- **FUNKAR EJ:** `00f00000` (inte OS-kod!)
- **FUNKAR:** `b7ce59ce` (korrekt OS-kod) ✅
- **Problem:** OS finns inte på rätt plats eller är korrupt
- **Impact:** EMAX II kan inte ladda OS

### 7. **CLUSTER SIZE FEL** ❌
- **FUNKAR EJ:** `204,800 bytes` (200 KB)
- **FUNKAR:** `489,472 bytes` (478 KB) ✅
- **Problem:** Fel cluster size för 239MB disk
- **Impact:** Diskstrukturen matchar inte förväntad storlek

## ⚠️ ZULUSCSI CONFIG PROBLEM

### FUNKAR EJ/zuluscsi.ini
```ini
; ZuluSCSI config for EMAX II
[SCSI]
EnableParity = 1

[SCSI1]
```
**Problem:**
- ❌ Saknar `[SCSI0]` section för boot disk
- ❌ Saknar `Vendor`, `Product`, `SectorSize` för både SCSI0 och SCSI1
- ❌ Saknar `MaxSyncSpeed`, `SelectionDelay` i [SCSI] section

### FUNKAR/zuluscsi.ini
```ini
[SCSI]
MaxSyncSpeed = 10
SelectionDelay = 255
StartupDelay = 0
```
**Problem:**
- ⚠️ Saknar `EnableParity = 1` (kritiskt för EMAX II!)
- ⚠️ Saknar `[SCSI0]` och `[SCSI1]` sections

**Rekommendation:** Båda behöver kompletteras!

## 📊 FRAGMENTERING PROBLEM

### FUNKAR EJ
```
WARNING: file /HD0.hda is not contiguous. This will increase read latency.
```
**Problem:** Filen är fragmenterad på SD-kortet
**Impact:** Ökad latens kan orsaka boot-timeout
**Lösning:** Defragmentera eller återskapa filen kontinuerligt

### FUNKAR
- ✅ Ingen varning om fragmentering
- ✅ Filen är kontinuerlig

## 🔧 LÖSNINGAR

### 1. Återskapa HD0.hda med korrekta värden

**Kritiska fixar som behövs:**
1. ✅ Boot signature: `0x78 0x82`
2. ✅ Bank count: `90` (för 239MB disk)
3. ✅ Cluster area start: `sector 98`
4. ✅ FAT[0]: `0x8000` (little-endian)
5. ✅ FAT[1]: `0x7FFF` (OS END marker)
6. ✅ OS på rätt plats: `clusterAreaStart + clusterSize` (0x83C00)
7. ✅ Cluster size: `489,472 bytes`

**Använd EmaxForge:**
- Skapa ny boot disk med "Create Bootable Disk" wizard
- Välj 239 MB storlek
- Inkludera OS
- Verifiera att alla värden är korrekta

### 2. Fixa ZuluSCSI Config

**Korrekt config ska vara:**
```ini
; ZuluSCSI configuration
; Generated by Emax Forge
; Device: EMAX II

[SCSI]
; Enable SCSI parity for EMAX II compatibility
EnableParity = 1

; Maximum synchronous transfer speed in MHz
MaxSyncSpeed = 10

; Selection delay (ms) — increase if host has trouble finding drive
SelectionDelay = 255

; Startup delay (ms) — wait before responding
StartupDelay = 0

[SCSI0]
Vendor = E-mu
Product = EMAX II HD
SectorSize = 512

[SCSI1]
Vendor = E-mu
Product = EMAX II HD
SectorSize = 512
```

### 3. Fixa Fragmentering

**Metod 1: Defragmentera**
```bash
# 1. Kopiera alla filer från SD-kortet
# 2. Formatera SD-kortet (FAT32, full format)
# 3. Kopiera tillbaka filerna i rätt ordning:
#    - Först: zuluscsi.ini
#    - Sedan: HD00.hda (kontinuerligt)
#    - Sedan: HD10.hda (kontinuerligt)
```

**Metod 2: Använd dd**
```bash
# Kopiera HD0.hda kontinuerligt till SD-kortet
dd if=HD0.hda of=/dev/diskX bs=1M conv=fsync
```

## ✅ VERIFIERING EFTER FIX

Efter fix, kontrollera:

1. **Boot signature:** `0x78 0x82` vid offset 0x1FE-0x1FF
2. **Bank count:** `90` vid offset 0x14
3. **Cluster area start:** `98` (0x62) vid offset 0x20
4. **FAT[0]:** `0x8000` vid offset 0x400
5. **FAT[1]:** `0x7FFF` vid offset 0x402
6. **OS data:** `b7ce59ce...` vid offset 0x83C00
7. **ZuluSCSI config:** Har `EnableParity = 1` och `[SCSI0]` section
8. **Ingen fragmentering:** Ingen varning i zululog.txt

## 📝 SLUTSATS
